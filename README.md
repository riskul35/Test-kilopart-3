# KiloPart - APK

Application de répartition de tonnage et de paye pour équipe de désosseurs.

## Comment récupérer l'APK (depuis téléphone)

1. Une fois ce code poussé sur GitHub, va dans l'onglet **Actions**
2. Clique sur le workflow **Build APK** qui vient de se lancer
3. Attends qu'il soit vert (environ 3-5 minutes)
4. En bas de la page, section **Artifacts**, télécharge **kilopart-apk**
5. Dézippe et installe le fichier `app-debug.apk` (autorise les sources inconnues)

## Notes

- L'APK est en version debug (non signé pour le Play Store)
- Toutes les données sont stockées en local sur le téléphone
